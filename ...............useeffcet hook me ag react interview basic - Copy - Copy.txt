You are using React's useState hook to manage three state variables:

data (Initially [])

Starts as an empty array ([]) because data is expected to hold a list of items fetched from an API.
When the data is retrieved, setData will update it with the fetched data.
loading (Initially true)

Starts as true because data is being fetched.
Once the data is loaded, setLoading(false) will be called to indicate loading is complete.
error (Initially null)

Starts as null because no error exists initially.
If an error occurs during the data fetch, setError(errorMessage) will update it with an error message.
Why these initial values?
null for error: Since there's no error initially, null represents the absence of an error.
[] for data: An empty array ensures that list-based operations (like .map()) won’t cause errors if data hasn’t been fetched yet.
true for loading: Ensures the UI knows that data fetching is in progress.

import { useEffect, useState } from "react";

function App() {
    const [data, setData] = useState([]);
    const [loading, setLoading] = useState(true);
    const [error, setError] = useState(null);

    useEffect(() => {
        // Define the API call function
        const fetchData = async () => {
            try {
                const response = await fetch("https://jsonplaceholder.typicode.com/posts");
                if (!response.ok) {
                    throw new Error("Failed to fetch data");
                }
                const result = await response.json();
                setData(result);
            } catch (err) {
                setError(err.message);
            } finally {
                setLoading(false);
            }
        };

        fetchData(); // Call the function

    }, []); // Empty dependency array = Runs only once on mount

    if (loading) return <p>Loading...</p>;
    if (error) return <p>Error: {error}</p>;

    return (
        <div>
            <h2>Fetched Data:</h2>
            <ul>
                {data.slice(0, 5).map((item) => (
                    <li key={item.id}>{item.title}</li>
                ))}
            </ul>
        </div>
    );
}

export default App;

React.js Interview Questions and Answers

Beginner-Level Questions

1. What is React?

React is a JavaScript library developed by Facebook for building user interfaces, especially for single-page applications. It allows developers to create reusable UI components.

2. What are the key features of React?

JSX: JavaScript XML syntax for writing UI components.

Components: Reusable building blocks.

Virtual DOM: Efficient UI rendering and updating.

Unidirectional Data Flow: Makes debugging easier.

Hooks: Allow state management in functional components.

3. What is JSX? Why is it used?

JSX (JavaScript XML) is a syntax extension for JavaScript that allows writing HTML elements in React components. It makes the UI code more readable and expressive.

4. What is the difference between functional and class components?

Functional Components: Simpler, use hooks for state and lifecycle management.

Class Components: Use this.state and lifecycle methods like componentDidMount.

5. What is the Virtual DOM, and how does it work?

Virtual DOM is a lightweight JavaScript representation of the actual DOM. React updates this virtual DOM first and then efficiently syncs it with the real DOM.

6. What are props in React? How are they different from state?

Props (short for properties) are immutable data passed from parent to child components. State is mutable data managed within a component.

7. What is the purpose of the key prop in lists?

key helps React identify which list items have changed, improving rendering performance.

8. What is state in React? How do you update it?

State is data managed within a component. It is updated using setState in class components or useState in functional components.

9. What is the difference between props and state?

Props: Passed from parent to child, immutable.

State: Managed within a component, mutable.

10. What is the use of useState hook?

useState allows functional components to manage state without using class components.

Intermediate-Level Questions

11. What are React Hooks?

Hooks are functions that let functional components use state and lifecycle features.

12. Explain the use of useEffect hook.

useEffect runs side effects (e.g., data fetching, subscriptions) after rendering.

13. What is the difference between useEffect and componentDidMount?

componentDidMount runs only once in class components.

useEffect runs on every render unless dependencies are specified.

14. What is useRef and when would you use it?

useRef provides a way to persist values across renders without triggering re-renders. Useful for accessing DOM elements.

15. How does useContext work in React?

useContext allows components to consume context values without needing prop drilling.

16. What is the useReducer hook, and how does it differ from useState?

useReducer is used for more complex state logic, similar to Redux reducers.

17. What is controlled vs uncontrolled components?

Controlled Components: Form elements whose state is controlled by React.

Uncontrolled Components: Form elements that manage their own state.

18. How do you handle forms in React?

Using controlled components, React state updates input values.

19. How does React handle conditional rendering?

Using ternary operators, && logical operators, or if statements.

20. How does React handle events?

React normalizes events using SyntheticEvent, ensuring cross-browser consistency.

Advanced-Level Questions

21. What is the difference between React’s useMemo and useCallback hooks?

useMemo: Memoizes computed values.

useCallback: Memoizes functions.

22. What is React Fiber, and how does it improve performance?

Fiber is a reimplementation of React’s rendering engine, optimizing reconciliation and rendering.

23. How does reconciliation work in React?

React compares the Virtual DOM with the real DOM and updates only changed parts.

24. What is the difference between client-side and server-side rendering (CSR vs SSR)?

CSR: React renders on the browser.

SSR: React renders on the server before sending the HTML.

25. What is React Suspense? How does it help with data fetching?

Suspense allows lazy loading components, improving performance.

26. What is lazy loading, and how can you implement it in React?

Lazy loading delays loading non-essential components using React.lazy() and Suspense.

27. What is Context API, and how does it replace Redux in some cases?

Context API provides global state management without needing Redux.

28. What is the difference between Redux and Context API?

Redux is more scalable, with middlewares like Thunk and Saga. Context API is simpler but less feature-rich.

29. What are Higher-Order Components (HOC)?

HOCs are functions that take a component and return a new enhanced component.

30. What is the purpose of error boundaries in React?

Error boundaries catch JavaScript errors in components and display fallback UIs.

Performance Optimization Questions

31. How can you optimize performance in a React app?

Using React.memo, useCallback, useMemo, lazy loading, and code splitting.

32. What are React fragments, and why are they useful?

Fragments (<>...</>) allow returning multiple elements without extra divs.

33. What are Pure Components in React?

Pure components re-render only when their props or state change.

34. What is the role of shouldComponentUpdate?

Prevents unnecessary re-renders in class components.

35. What is the difference between React.memo and useMemo?

React.memo memoizes entire components.

useMemo memoizes computed values.

React Router and State Management Questions

51. What is React Router, and how does it work?

React Router enables client-side navigation using components like <Route> and <Link>.

52. How do you handle dynamic routes in React Router?

Using :param in the route path and useParams() hook.

53. What are nested routes in React?

Routes inside other routes, managed using <Outlet>.

54. How do you programmatically navigate in React Router?

Using useNavigate() or history.push() in older versions.

55. What is the difference between Redux and React Context API?

Redux is better for large-scale apps with middleware; Context API is lightweight.

Testing and Debugging Questions

61. How do you test React components?

Using Jest and React Testing Library.

62. What is Jest, and how is it used in React testing?

Jest is a JavaScript testing framework used for unit tests.

63. What is the difference between shallow rendering and deep rendering?

Shallow rendering tests a single component; deep rendering tests its children too.
